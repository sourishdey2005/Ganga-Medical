## 🚀 Key Features
- **Online Medicine Catalog**: Browse a wide range of genuine medicines and healthcare products.
- **Easy Prescription Upload**: Simple multi-step process for users to upload medical prescriptions for pharmacist review.
- **Functional Order System**: Real-time cart management allowing users to build an order list and provide delivery details.
- **AI-Powered Support (Ganga AI)**: Integrated Genkit chatbot to assist with store timings, order status, and availability queries.
- **Staff Management Dashboard**: Secure portal for pharmacists to manage inventory and verify orders.
- **Digital Health Services**: Direct links for booking doctor consultations and blood tests.

## 🛠️ Tech Stack
- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) & [Shadcn UI](https://ui.shadcn.com/)
- **AI Integration**: [Genkit](https://firebase.google.com/docs/genkit) (Gemini 2.5 Flash)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 📦 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:9002](http://localhost:9002) in your browser.
