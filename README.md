# Ganga Medical - Professional Digital Pharmacy

Ganga Medical is a modern, trust-inspired digital pharmacy application designed for **Ganga Medical Stores (Balichak)**. This platform enables users to browse medicines, upload prescriptions, and access professional healthcare services directly from their doorstep in Balichowk.

## 🚀 Key Features

- **Dynamic Medicine Catalog**: Browse a wide range of genuine medicines categorized by health needs.
- **Secure Prescription Upload**: Simple multi-step process for users to upload medical prescriptions for pharmacist review.
- **Functional Order System**: Real-time cart management allowing users to build an order list and provide delivery details.
- **AI-Powered Customer Support**: Integrated Genkit chatbot ("Ganga") to assist with store timings, order status, and availability queries.
- **Admin & Pharmacy Dashboard**: Dedicated staff portal with hardcoded secure access to manage orders and inventory.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop using Tailwind CSS and Shadcn UI.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [Shadcn UI](https://ui.shadcn.com/)
- **AI Integration**: [Genkit](https://firebase.google.com/docs/genkit) (Gemini 2.5 Flash)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 📦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sourishdey2005/Ganga-Medical.git
   cd Ganga-Medical
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Set up Environment Variables**:
   Create a `.env` file in the root directory and add your Firebase and Genkit configuration keys.

4. **Run the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:9002](http://localhost:9002) with your browser to see the result.
